        Help
        
    
        
      
        Running a program
        
      
        Type your program and press Run (or F10). Anything the program reads with scanf must be typed into the Input box first, because the program cannot pause for the keyboard while it runs. Compile (F9) only checks the program and lists errors and warnings.
        
      
        Files
        
      
        Add data files under Files (File menu, Add input files) and open them in the program with fopen("data.txt", "r"). Files your program writes appear under Output, where you can view, download, or use them as input for the next run.
        
      
        Keyboard shortcuts
        
      
        
        
        F10, Ctrl+EnterCompile and run
        
        
        F9Compile only
        
        
        Ctrl+SSave as a .c file
        
        
        Ctrl+OOpen a .c file
        
        
        Ctrl+FFind and replace
        
        
        F3 or Ctrl+GFind next
        
        
        Ctrl+Alt+GGo to line
        
        
        Ctrl+/Comment or uncomment lines
        
        
        Ctrl+Z, Ctrl+YUndo, Redo
        
        
        EscClose a menu, or restore an enlarged panel
