C Programming Tutorial

Never written a program before? Start by making the computer say hello.

You can do every lesson in your browser. Run a short example, change one thing, and see what happens. Later, you’ll use C to count, make choices, and work with a list of game scores.

Run your first program

Start here: run your first program

A program is a set of instructions a computer can follow. C is one language for writing those instructions. The words and symbols you type in the editor are called source code.

When you press Run, CLab first uses a compiler to turn your C code into a program it can run. The program prints a message in the Output panel. That message is the result you see.

Fix your first mistake

Read the first error and look at the line it points to. Sometimes the cause is on the line just above it. Fix one thing at a time and press Run again.

Variables and values

Imagine you have four stickers. You can give that number a name in your program. In int stickers = 4;, stickers is a variable. It has a name, a type and a starting value. Here int is a type for whole numbers within a fixed range.

You can change the value later with stickers = stickers + 2;. C first adds 2 to the old value, then stores the result in stickers. In printf, write %d where you want an int value to appear.

What number is stored after stickers = stickers + 2; if stickers started at 4?

Whole numbers, decimals and characters

Use int for a count such as 3 notebooks. Use double for numbers that may have a fractional part, such as a price of 2.50. Use char for a single character such as 'A'. A character such as 'A' uses single quotation marks. Text such as "Team A" uses double quotation marks.

In printf, %d prints an int, %.2f prints a double rounded to two digits after the decimal point, and %c prints a character. Write a value of the right type after the comma. The example uses (int)team to give %c the int it expects.

Arithmetic and conversions

Suppose 5 friends share 17 whole cookies equally. Each friend gets 3 cookies, and 2 are left over. In C, 17 / 5 gives 3 and 17 % 5 gives 2. When both numbers are integers, C drops the fractional part of the quotient. The divisor must be nonzero.

If you can cut the cookies, the share is 3.4 cookies. Write (double)total / groups to convert the first number before dividing. This conversion is called a cast.

Quick quiz

What is 17 % 5?
Show answer

2. Three groups of 5 use 15. The remainder is 2.

Decisions with if and else

A game can show a message based on the player’s score. Use if to ask a yes-or-no question such as score >= 75. Use else if to ask another question when the first answer is no. The final else covers every score left.

== compares values, while = assigns a value. Use && for a conjunction and || for a disjunction. They evaluate left to right and skip the second operand if the first already determines the result.

Read a number with scanf

Use printf to ask a question and scanf to read the answer. In scanf("%3d", &number), d tells C to read a whole number. The 3 lets it read at most three characters of the number, including a plus or minus sign. &number tells C where to store the answer.

This call to scanf gives back 1 when it stores a number. Check for 1 before using number. The call to fflush(stdout) makes the prompt appear before the program waits for input.

Loops with for and while

A loop repeats instructions. Think of adding one number at a time from 1 to 5. The for loop starts at 1, checks whether it has gone past 5, adds the current number, and then moves to the next number. A while loop also checks its condition before each repeat.

A do–while loop tests after its body and therefore runs at least once. In this program, the counter in the for loop ranges from 1 through 5, inclusive.

Arrays and bounds

Keep four game scores in one ordered list called an array. Every value in the list has the same type. Its position is called its index. The first score is scores[0] and the fourth is scores[3]. Stay within those positions. C gives no reliable result when you go outside the array.

For an array object in scope, sizeof scores / sizeof scores[0] gives the number of elements. The result has type size_t. To declare a 2 × 3 array of integers, use int grid[2][3]; and access its elements as grid[row][column].

Strings and the null character

Text such as "cat" is called a string. C stores it as the letters followed by a special end marker called the null character '\0'. A character array holding a string needs capacity for that final character.

strlen counts the bytes before the terminator. sizeof on the array gives its full capacity in bytes. Use strcmp(a, b) == 0 to test string contents for equality. You can change the elements of the array initialized below. Attempting to modify a string literal itself has undefined behavior.

Pointers and addresses

A variable lives at a location in memory. A pointer can hold that location, called an address. Write &x to get the address of x. If p holds that address, *p lets you read or change the value there. The example uses two addresses to swap two scores.

Dereference only a pointer that points to a suitable, live object. A null pointer has no object to point to. In the example, *a = *b; changes the score at the first address. Writing a = b; would only change which address the local pointer holds.

Structures and records

A point on a map has two coordinates. You can keep both together in a structure, written struct in C. Each named part is a member. Write p.x for the x part of p, or point->x if point is a pointer to it.

When you make the point, write .x = 2.0 and .y = 3.0 to give both parts their starting values. The names show which number goes with which part.

Sometimes you only find out how many scores to store while your program is running. malloc asks for space in memory. Multiply the number of scores by the size of one score, given by sizeof *values. This example uses four scores. For a count entered by the user, check that it is valid and that the multiplication fits before you ask for space.

Check for a null result before accessing the allocation. malloc leaves the storage uninitialized, so write values before reading them. Release the memory with free when finished and avoid using pointers to the freed storage.
