C Programming Tutorial

Learn C one program at a time, from your first line of output to a project that summarizes a data set.

These lessons use ISO C17. Each example opens in a separate CLab practice tab with the sample input or files already loaded. Press Run to compare the result with the expected output. To keep changes from a practice tab, download the program with File → Save.

Variables, types and formatted output

Choose a type when you declare a variable. Use int for whole numbers within its range, double for floating-point values, and char for a character such as 'A'. Initialize local variables before reading their values.

In printf, %d expects an int, %.2f prints a double with two digits after the decimal point, and %c prints a character passed as an int. Match the format to the argument type. Use \n to end a line.

Arithmetic and conversions

When both operands of / have integer type, the quotient is truncated toward zero. The % operator gives the remainder for integer operands. Keep the divisor nonzero.

Cast an operand to double before division when you want a floating-point quotient. Use parentheses when the grouping matters. A signed integer result outside the type’s representable range has undefined behavior.

Decisions with if and else

Use if to execute a block when its condition is nonzero. An else if chain tests conditions in order and executes the first matching block. The final else handles the remaining cases.

== compares values, while = assigns a value. Use && for a conjunction and || for a disjunction. They evaluate left to right and skip the second operand if the first already determines the result.

Multiple choices with switch

Use switch to choose among cases for an integer-valued expression. Each case label uses an integer constant expression. Use default for unmatched values.

Execution starts at the matching label. A break exits the switch. Without it, execution can continue into the following case.

Loops with for and while

Use a for loop when a counter organizes the work. The initializer runs once. The condition is checked before each iteration and the update runs after the body. A while loop also checks before each iteration.

A do–while loop tests after its body and therefore runs at least once. In this program, the counter in the for loop ranges from 1 through 5, inclusive.

Hint

Advance the counter by 2 each time.

Answer

Use for (int i = 2; i <= 10; i += 2). The sum is 30.

Arrays and bounds

An array stores a fixed number of elements of the same type in order. Its first element has index 0. An array of length n can be indexed from 0 through n − 1. Access outside this range has undefined behavior.

For an array object in scope, sizeof scores / sizeof scores[0] gives the number of elements. The result has type size_t. To declare a 2 × 3 array of integers, use int grid[2][3]; and access its elements as grid[row][column].

Strings and the null character

A C string is a sequence of characters terminated by the null character '\0'. A character array holding a string needs capacity for that final character.

strlen counts the bytes before the terminator. sizeof on the array gives its full capacity in bytes. Use strcmp(a, b) == 0 to test string contents for equality. You can change the elements of the array initialized below. Attempting to modify a string literal itself has undefined behavior.

Functions and parameters

A function can receive arguments and return a result. Provide a declaration before its first call, either by defining the function earlier or by using a prototype as below. Local variables declared inside a function body are scoped to their block.

C passes arguments by value. Each parameter receives a value derived from its argument. A function that accepts an array through a parameter such as int a[] actually receives a pointer. Pass the element count separately.

← Strings and the null character Pointers and addresses →

Pointers and addresses

A pointer can hold the address of an object. &x gets the address of x, and *p accesses the object to which p points. Use a pointer to let a function update an object owned by its caller.

Dereference only a pointer that points to a suitable, live object. A null pointer points to no object. A pointer argument is itself passed by value, so assigning to the parameter changes only the function’s local copy of the pointer.

Dynamic memory with malloc and free

Use malloc to request storage whose lifetime you control. Use sizeof *values to calculate the size of one element. For a count supplied by the user, validate it and check that the multiplication fits in size_t before allocating.

Check for a null result before accessing the allocation. malloc leaves the storage uninitialized, so write values before reading them. Release the memory with free when finished and avoid using pointers to the freed storage.

Expected output

Exercise

What should you check before allocating count elements if count comes from input?

Hint

Think about empty input and the largest value a size_t can hold.

Answer

If the program needs at least one element, require count > 0. Reject count > SIZE_MAX / sizeof *values before multiplying. Include <stdint.h> for SIZE_MAX.

Reading a text file
