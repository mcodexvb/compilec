How a computer runs your program

← Previous Next →

A computer has a processor (CPU) that carries out instructions, main memory (RAM) that holds the running program and its data, secondary storage such as a disk that keeps files when the power is off, and input and output devices such as the keyboard and the screen. Inside the CPU, a control unit fetches and decodes each instruction, an arithmetic logic unit (ALU) does the calculations, and a few very fast cells called registers hold the numbers being worked on. Everything in memory is a pattern of bits, each 0 or 1, grouped into bytes of eight bits.

The program below shows the same number, 202, the way people write it and the way the machine holds it.

The pattern 11001010 is what is stored. Machine instructions are stored the same way: each one is a binary pattern that tells the CPU to add, compare, move a value or jump to another instruction. A program in machine language is a long list of such patterns. Nobody writes them by hand, so programming languages exist at three levels.

LevelWhat it looks likeTranslated by
Machine languageBinary patterns such as 11001010Nothing: the CPU runs it directly
Assembly languageOne short name per instruction, such as ADD or MOVAn assembler
High-level languageStatements close to mathematics, such as c = a + b;A compiler or an interpreter

One C statement usually becomes several machine instructions. This is an illustration only, written in a made-up assembly language:

C statement:   c = a + b;
      
      Machine-like   LOAD  R1, a
      steps:         LOAD  R2, b
                     ADD   R1, R2
                     STORE R1, c

A compiler translates the whole program into machine code before anything runs. It reports errors in the source, and then the translated program runs at full speed. An interpreter reads one statement at a time, translates it and runs it at once. It needs no separate translation step, but it repeats the translation work every time and an error is found only when the interpreter reaches that statement. C is normally compiled. Python is normally interpreted.

CLab follows these steps with the Clang compiler, which produces WebAssembly, a compact machine-like language that every modern browser can run.

Languages also differ in how a program is organised. In a procedural language such as C, the program is a collection of functions (procedures) that carry out the steps and work on the data passed to them. In an object-oriented language such as C++ or Java, data and the functions that act on it are bundled together into objects that belong to a class, and the program is built around how those objects interact. C is procedural. Its relative C++ adds objects, and CLab can compile C++ too.

Character set, constants and declarations

← Previous Next →

C programs are written with the C character set: the 52 letters a–z and A–Z, the ten digits 0–9, special characters such as + - * / % = < > ( ) [ ] { } ; , . # & ! ? _, and white space (blank, tab, newline). The computer stores each character as a small whole number, its code. In ASCII, 'A' is 65, 'a' is 97 and '0' is 48.

A constant is a value that does not change while the program runs. C has several kinds:

KindExamplesNotes
Integer42, 052, 0x2A, 100000LNo decimal point. A leading 0 means octal and 0x means hexadecimal, so these first three are all 42.
Floating-point3.14, 2.5e3, 1.5E-2A decimal point or an exponent. The type is double.
Character'A', '7', '\n'Single quotes. The value is the character code.
String"C", "Hello\n"Double quotes. An array of characters ending with '\0'.

Escape sequences write characters that are hard to type: \n newline, \t tab, \\ backslash, \' and \" quotes, \0 the null character.

The example names constants in three ways. #define PI 3.14159265 makes the preprocessor replace every PI by that text before compiling; it has no type and no semicolon. const int days_in_week = 7; declares a real variable that the compiler will not let you change. An enum gives names to whole numbers: MON is 1, and each following name is one more, so WED is 3.

A declaration tells the compiler a variable’s type and name before it is used: int count; or double rate = 7.5;. Writing = 7.5 as well initializes it. A local variable that is not initialized holds an unpredictable value. A name may contain letters, digits and underscores, must not start with a digit, is case-sensitive (Total and total differ) and must not be a keyword such as int or while.

Relational, logical and assignment operators

← Previous Next →

Programs make decisions by comparing values. A relational expression such as a > b has the value 1 if it is true and 0 if it is false. Logical operators combine such tests. Assignment operators store results in variables.

OperatorsMeaning
< <= > >=less than, less than or equal, greater than, greater than or equal
== !=equal to, not equal to
&& || !and, or, not
= += -= *= /= %=assign; x += 5 means x = x + 5
++ --add or subtract 1
? :test ? a : b gives a if the test is true, else b

Study each line of output. Writing 1 <= a <= 10 does not work in C, so the range test is written a >= 1 && a <= 10. With x, each compound assignment changes the value in turn: 10, 15, 12, 24, 6, 2. In j = i++ the old value of i is used and then i grows. In k = ++i it grows first and the new value is used.

The operators && and || evaluate left to right and stop as soon as the answer is known. Here d != 0 is false, so 10 / d is never evaluated. Always place the safety test first.

When a line has several operators, C applies them in order of precedence, highest first: parentheses; !, ++, --; * / %; + -; < <= > >=; == !=; &&; ||; ?:; and last the assignments. Add parentheses whenever the order is not obvious. One classic slip: if (a = 5) assigns 5 and is always true. You almost always mean if (a == 5).

Nested if and the else-if ladder

← Previous Next →

Often one question is not enough. An else-if ladder tests several conditions in order and runs only the first block whose test is true. A nested if places one if inside another, so the inner test is made only when the outer one succeeded.

The first loop below turns marks into grades with a ladder. The second decides leap years with nested tests: a year divisible by 4 is a leap year unless it is a century, and a century is a leap year only if it is divisible by 400.

In the ladder, 92 satisfies m >= 90 at once, so the other tests are skipped. Order matters: if the test m >= 50 came first, 92 would be graded C.

An else always belongs to the nearest if that does not yet have one. When ifs are nested, write the braces { } even around single statements. They make the structure visible and prevent the “dangling else” mistake, where an else pairs with a different if than the indentation suggests.

Exercise

Hint

A leap year is divisible by 4 but not by 100, or divisible by 400.

Answer

(y % 4 == 0 && y % 100 != 0) || y % 400 == 0. It gives the same results for 1900, 2000, 2024 and 2026.

Quick quiz

In the grade ladder, how many tests after the first run for 95 marks?
Show answer

None. The first test m >= 90 is true, and the rest of the ladder is skipped.

do–while, break and continue

← Previous Next →

A do–while loop tests its condition after the body, so the body always runs at least once. That suits menus and input checks, where you must act before you can test. Two statements change the normal flow of any loop: break leaves the loop at once, and continue skips the rest of the current pass and goes on to the next.

The first do–while counts down from 3. The second runs its body once although its condition c < 0 is false from the start; a while loop would not have run at all. Notice the semicolon after while (…) in a do loop.

In the for loop, continue skips the multiples of 3, so the printf after it is not reached for those values. The last loop has no condition at all and would run forever, but break ends it at the first multiple of 7. In nested loops, break leaves only the innermost loop.

Exercise

Print the numbers from 1 to 20, but stop before the first multiple of 6.

Hint

Answer

Quick quiz

What does continue do inside a for loop?
Show answer

It skips the rest of the current pass. The loop then moves on to its update expression and the next test.

Two-dimensional arrays and matrices

← Previous Next →

An array can have more than one dimension. A two-dimensional array is declared int a[2][3];, which means 2 rows and 3 columns, so 6 elements in all. The element in row i, column j is a[i][j], and both indices start at 0. It matches a matrix in mathematics, with one difference: mathematicians count from 1.

The nested braces in an initializer follow the rows: {{1, 2, 3}, {4, 5, 6}}. The usual way to visit every element is a pair of nested loops, the outer one over rows and the inner one over columns.

The program sums each row and, in the same loops, copies element a[i][j] to t[j][i], which builds the transpose. A third index gives a three-dimensional array, such as cube[2][2][2]; the same idea extends to any number of dimensions.

C stores a two-dimensional array row by row in one block of memory, so a[1][0] comes straight after a[0][2]. The expressions sizeof a / sizeof a[0] and sizeof a[0] / sizeof a[0][0] give the number of rows and columns, as the last line shows. As with one-dimensional arrays, C does not check the indices, so stay within the declared bounds.

String functions from string.h

← Previous Next →

A string is an array of characters ending with '\0', so the operators = and == cannot copy or compare whole strings. The header string.h provides functions that do these jobs.

FunctionWhat it does
strlen(s)number of characters before the '\0'
strcpy(dest, src)copies src into dest
strcat(dest, src)appends src to the end of dest
strcmp(a, b)negative if a comes first alphabetically, 0 if equal, positive if a comes after
strchr(s, c)address of the first c in s, or NULL

Only the sign of the result of strcmp is specified, so the program tests < 0, never a particular number. Subtracting the address of the start of the string from the address strchr returns gives the index of the character.

strcpy and strcat do not check sizes. The destination array must be large enough for the text and the final '\0', otherwise the program writes past the end of the array. Comparison is by character code, so every uppercase letter sorts before every lowercase one: "Zed" comes before "apple".

Show answer

Scope of variables and call by value

← Previous Next →

The scope of a variable is the part of the program where its name can be used. A variable declared inside a function or block { } is local: it exists only there. A variable declared outside every function is global and can be used by all the functions below it. A local variable declared static is still local, but it keeps its value from one call to the next.

When a function is called, C copies each argument into the matching parameter. This is call by value: the function works on copies and cannot change the caller’s variables.

The function try_to_change adds 1 to its copy, so x in main stays 5. The braces in main create a new block whose own x hides the outer one while the block lasts. The static variable id in next_id is set to 0 only once, so the three calls return 1, 2 and 3.

A function may call another function. This is how larger programs are built from small, tested pieces: hypotenuse calls square twice and passes the result to the library function sqrt. C does not allow one function to be defined inside another, but nested calls such as sqrt(square(a) + square(b)) are everywhere. To let a function change the caller’s variable, pass its address; that is the topic of the Pointers lesson.

The variable is still 3, because v is a copy. To change the original, the function must receive its address (int *v) and be called as increase(&x).

Passing arrays to functions

← Previous Next →

An array is not copied when it is passed to a function. The function receives the address of the first element, so it works on the caller’s own array. That has two consequences. The function can change the elements, and it cannot tell how long the array is, so the length is passed as a separate argument.

Add const to a parameter such as const int a[] when the function should only read the array. For a two-dimensional array, the number of columns must appear in the parameter, as in int m[][3], so the compiler can compute where each row begins.

average only reads the marks. double_all changes them, and the caller sees the change: the second average is twice the first. This is the usual way to make a function modify several values at once. row_sum receives the whole grid and adds one row.

Notice that the array name alone, marks, is the argument, with no brackets and no &. Inside the function, sizeof a would give the size of a pointer, not of the array, which is why n is needed.

Recursive functions

← Previous Next →

A recursive function calls itself. Every correct recursive function has two parts: a base case that returns an answer directly, and a recursive case that solves a smaller version of the same problem. The factorial shows both: 1! = 1 is the base case, and n! = n × (n−1)! is the recursive case.

The first program prints a line when each call starts and when it returns, indented by depth, so you can watch the calls pile up and then unwind.

Each call waits for the call below it. factorial(1) returns first, then factorial(2) uses that answer, and so on back up. The computer keeps the waiting calls on the call stack, one frame for each, and a function with no base case would fill the stack and crash the program.

The other functions use the same pattern. The greatest common divisor satisfies gcd(a, b) = gcd(b, a mod b) and stops when b is 0. The Fibonacci numbers satisfy fib(n) = fib(n−1) + fib(n−2) with fib(0) = 0 and fib(1) = 1. The digit sum of n is its last digit plus the digit sum of n / 10. Recursion is elegant, but fib as written repeats work and becomes slow for large n; a loop is faster.

Exercise

Write a recursive function power(int base, int exp) and print power(2, 10).

Hint

The base case is exp == 0, which gives 1.

Answer

int power(int base, int exp) { return exp == 0 ? 1 : base * power(base, exp - 1); }. The result is 1024.

Quick quiz

What happens if a recursive function has no base case?
Show answer

Each call needs a new stack frame, so the calls never stop until memory for the stack runs out.

Pointers and addresses

← Previous Next →

To swap two scores in main, pass their addresses to the swap function. &left gets the address of left. A pointer such as a holds an address, and *a refers to the object there.

The assignment *a = *b; changes the original score. The temporary variable keeps the first score from being overwritten before the function can move it to the second position. Only dereference a pointer that points to a live object.

Problem 16. Write a program to check whether two given strings are an anagram.

Each test is a function that returns 1 or 0, so the same functions can also list all such numbers up to a limit.

Problem 18. Write a program to check whether a number is a prime number or not.

A number above 1 is prime if no integer from 2 up to its square root divides it. If n had a divisor larger than √n, it would also have a smaller partner, so the loop can stop when d * d > n.

Problem 19. Prepare a code for summing a Series.

The program adds the series ex = 1 + x + x²/2! + x³/3! + … until a term is smaller than the tolerance. Each term comes from the previous one, term = term * x / n, so no factorial or power is ever computed. To sum another series, change the first term, the update rule and the stopping test.

Show solution

Problem 20. Compute approximate value of pi .

Two series are compared. The Leibniz series π/4 = 1 − 1/3 + 1/5 − … is simple but very slow: a thousand terms give about three correct digits. The Nilakantha series π = 3 + 4/(2·3·4) − 4/(4·5·6) + … reaches nine digits with the same number of terms. The true value comes from acos(-1.0).

Problem 21. Compute the area under a given curve.

The area is the integral of f from a to b, approximated by the trapezoidal rule and by Simpson’s 1/3 rule with n strips of width h = (b−a)/n. Simpson’s rule needs an even n. For y = x² + 1 on [0, 3] the exact area is 12, and Simpson’s rule is exact for polynomials up to degree 3. To use another curve, change the function f.

Show solution

Problem 22. Solve a quadratic equation.

The discriminant b² − 4ac decides the case: positive gives two real roots, zero gives equal roots and negative gives a complex pair. The program also handles a = 0, where the equation is not quadratic. Try the input 1 2 5 to see complex roots.

Show solution

Problem 23. Write a program to solve a system of linear equations in two unknowns.

Cramer’s rule gives x = Dx/D and y = Dy/D, where D = a₁b₂ − a₂b₁. If D = 0 the lines are parallel or the same line, which the program tells apart. The sample solves 2x + 3y = 8 and x − y = −1.

Show solution

Problem 24. Write a program to find the shortest distance between two straight lines (parallel or intersecting or skew) in space.

Write the lines as r = p + tu and r = q + sv. If u × v = 0 the lines are parallel and the distance is |(q−p) × u| / |u|. Otherwise the distance is |(q−p) · (u × v)| / |u × v|, and it is 0 when the lines intersect. A struct for vectors and small functions for the cross and dot products keep the main program readable. Since decimal numbers are never compared exactly, the tests use a small tolerance.
