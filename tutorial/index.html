C Programming

A practical introduction to C, from printing your first line to working with arrays, pointers, and files.

Run the examples in CLab, then change the code and check what happens. No previous programming experience is required.

Start here: run your first program

A C program is text you write for a computer to follow. That text is called source code. Open the example below to see the source in CLab’s editor.

When you press Run, the compiler translates the source into a form your browser can execute. The output of this program is one line, Hello!.

  1. Select Run in CLab to open the example in a new tab.
  2. Press Run. The first run may take a little longer while CLab loads the compiler.
  3. Look for Hello! in Output. On a phone, the Output tab opens when you run the program.

Exercise

Make the program say Hello, Sam! or use your own name.

Hint

Change the greeting inside the quotation marks. Keep \n at the end to start a new line.

Answer

Change the line to printf("Hello, Sam!\n"); and press Run again.

Quick quiz

Where do you look for the message after pressing Run?
Show answer

In the Output panel. The Output panel shows what your program prints.

Read a C program line by line

Execution starts in main. Its opening and closing braces surround the statements that run when the program starts. In this example, the two printf statements run in the order they’re written.

The #include <stdio.h> line makes the declaration of printf available. The // line is a comment for readers. A semicolon ends each call and the return statement. Returning 0 reports that the program finished successfully.

Exercise

Swap the two printf lines. Predict what will print first. Then change the comment and run again.

Hint

The instructions inside main here run in order. A comment begins with // and continues to the end of its line.

Answer

The program prints Go! first. The comment is for the reader, so changing it leaves the result the same.

Quick quiz

Where do the instructions inside main go?
Show answer

Between the curly braces. The curly braces surround the instructions in main.

printf leaves the cursor where its text ends. In the example, the first call prints Red followed by a space. The second call continues on the same line.

Write \n inside the quotation marks to start a new line. That pair of characters stands for a single newline. The last call prints Green on the new line.

Exercise

Make Red, Blue, and Green appear on three separate lines.

Hint

Put a \n at the end of each message.

Answer

Use printf("Red\n");, printf("Blue\n");, and printf("Green\n");.

Quick quiz

What does \n do inside a message?
Show answer

It starts a new line. C treats the backslash and n together as a newline.

Fix your first mistake

Try breaking this short program on purpose. A missing semicolon is a syntax error, which means the compiler can’t make sense of how the code is written.

Start with the first error in CLab’s Output panel. Inspect the line it points to and the line just above it. The compiler may only discover that a semicolon is missing when it reaches the next statement.

Exercise

Remove the semicolon at the end of the printf line and press Run. Read the error. Put the semicolon back and run again.

Hint

Look for a message about an expected ;. Check the end of the line that prints the message.

Answer

The line should end with );. With the semicolon back in place, CLab prints Ready to play!.

Quick quiz

You see an error about an expected ;. What should you check first?
Show answer

The end of the line near the error. Look at the end of the line the compiler points to and the one just above it.

Variables and values

To keep track of four stickers, declare int stickers = 4;. The type int gives the variable a range of whole numbers it can store. The name is stickers and the initial value is 4.

In stickers = stickers + 2;, C works out the right side first and stores the result on the left. In printf, %d marks where the integer value will appear.

Exercise

Start with 5 stickers. Give one to a friend. What will the program print?

Hint

Change the starting value and use subtraction to give away a sticker.

Answer

Use int stickers = 5; and stickers = stickers - 1;. You start with 5 stickers and finish with 4.

Quick quiz

What number is stored after stickers = stickers + 2; if stickers started at 4?
Show answer

6. C adds 2 to the old value of 4 and stores 6.

Whole numbers, decimals and characters

A notebook count, a price, and a team letter need different types. The example uses int for a whole-number count, double for a number with a fractional part, and char for a letter. Write a character like 'A' in single quotes and text like "Team A" in double quotes.

Match the format to the value in printf. Use %d for int, %.2f for a double printed to two decimal places, and %c for a character. The cast (int)team supplies the int argument expected by %c.

Exercise

Change the team to B and the price to 3.75.

Hint

Keep single quotation marks around the new team letter. Write the new price as a number.

Answer

Use char team = 'B'; and double price = 3.75;.

Quick quiz

Which declaration can hold the decimal value 2.50?
Show answer

double price = 2.50;. double can hold a fractional part. The int declaration would store 2.

Arithmetic and conversions

Share 17 cookies equally among five people. Each gets three whole cookies, with two left over. In C, 17 / 5 gives 3 and 17 % 5 gives 2. When both operands are integers, the quotient is truncated toward zero. The divisor must be nonzero.

If you can cut the cookies, the share is 3.4 each. Cast one operand to double before dividing to get a fractional result. Try casting after the division and see what changes.

Exercise

Predict the result of (double)(total / groups).

Hint

Evaluate the expression inside the inner parentheses first.

Answer

Integer division produces 3, which the cast converts to 3.0.

Quick quiz

What is 17 % 5?
Show answer

2. Three groups of 5 use 15. The remainder is 2.

Decisions with if and else

The program checks the score from top to bottom. A score outside 0–100 gets an error message. Otherwise, a score of at least 75 earns a distinction, and one of at least 40 earns a pass. The final else handles the remaining scores.

Read == as “is equal to” and = as assignment. The operator || means “or” and && means “and”. C evaluates the right operand only when it needs it to decide the result.

Exercise

Test the program with 39, 40, 75 and 101.

Hint

Pay attention to whether the lower boundary is included.

Answer

The outputs are Try again, Pass, Distinction and Invalid score, respectively.

Quick quiz

With a score of 72, which message does the example print?
Show answer

Pass. 72 is below 75 and at least 40, so it reaches the Pass branch.

Read a number with scanf

printf displays the prompt. scanf reads the answer. In scanf("%3d", &number), %d reads a signed decimal integer, the field width 3 limits the number to three characters including any sign, and &number gives the address where C should store it.

Read number only if scanf returns 1, which means one value was stored. The field width limits what is read, so extra characters can remain in the input. fflush(stdout) makes the prompt visible before the program waits for an answer.

Exercise

Try 42, -12, and cat. Then try 1234 and see what the three-character limit does.

Hint

Enter one test value in Prepared input, or clear it and type your answer in Output when asked.

Answer

The first two print 42 and -12. With cat, scanf stores nothing and the program prints an error. With 1234, it reads the first three digits and prints 123.

Quick quiz

What does this call to scanf give back when it successfully reads one number?
Show answer

1. scanf stores the input in number and gives back 1 because it stored one value.

Multiple choices with switch

A one-letter menu is a good fit for switch. It compares the value of choice with the listed cases. Each case label is an integer constant expression, such as the character constant 's'.

A match starts execution at that label. The break ends the switch. If you leave it out, execution can continue into the next case. If there is no match, execution starts at default when that label is present.

Exercise

Add a 'r' choice that prints Range.

Hint

Add a case before default and test it.

Answer

Add case 'r': printf("Range\n"); break; and assign 'r' to choice.

Quick quiz

What is the job of break inside this switch?
Show answer

Leave the switch. break leaves the switch after the matching case runs.

Loops with for and while

Trace the first loop with a pencil. It sets i to 1, checks i <= 5, and adds i to the sum. The ++i runs after the body, then the condition is checked again.

The second loop counts down using while. Both loops test their conditions before running the body. A do–while loop places that test after the body, so its body runs at least once.

Exercise

Sum the even integers from 2 through 10.

Hint

Advance the counter by 2 each time.

Answer

Use for (int i = 2; i <= 10; i += 2). The sum is 30.

Quick quiz

What is the last value added by the first loop?
Show answer

5. The condition i <= 5 includes 5.

%3d reserves at least three character positions for each number, so the columns line up in a monospaced font. Print the newline after the inner loop to put each row on its own line.

Exercise

Change the table to four rows and five columns. Check the bottom-right number.

Hint

Answer

Set the row limit to 4 and the column limit to 5. The bottom-right number is 20.

Build a number pyramid

Look at the third row of the pyramid. It prints some spaces, then 123, then 21. The biggest digit appears once, in the middle.

For row row, print height - row spaces. Count up from 1 through row, then down from row - 1 through 1. The one-digit layout works for heights 1 through 9.

Exercise

Make a pyramid with five rows. Predict the first and last rows before you run it.

Hint

Change only height. Each row uses that value to figure out its spaces.

Answer

Set height to 5. The first row is four spaces followed by 1. The last row is 123454321. Keep the height at 9 or less so each number uses one digit.

Show answer

Arrays and bounds

Store four game scores in an array when you want to process them together. The first score is scores[0] and the fourth is scores[3]. Access outside the bounds of an array has undefined behavior.

Within the scope of the array declaration, divide the size of the whole array by the size of its first element to get the count. The result has type size_t. In a function that receives an array as a pointer, pass the count separately.

Exercise

Add a fifth score of 15 and predict the mean.

Hint

The loop already uses the length computed from the array.

Answer

The new sum is 45, and the new mean is 9.00.

Quick quiz

Which expression reads the fourth score?
Show answer

scores[3]. The first score is at index 0, so the fourth score is at index 3.

Strings and the null character

C represents a string as a sequence of characters ending at the first null character, '\0'. The string "cat" takes four array positions because it needs space for that last character.

strlen counts the bytes before the null character. sizeof gives the full size of the array in this example. For comparing strings, strcmp(a, b) == 0 means that the two strings match.

Exercise

Change bat to boat using assignments.

Hint

Update the changed letters and leave a terminator after the last one.

Answer

Set word[1] = 'o'; word[2] = 'a'; word[3] = 't'; word[4] = '\0';. The new length is 4.

Quick quiz

How many array slots does the C string bat need at minimum?
Show answer

4. It needs three letters and one slot for the end marker.

Pointers and addresses

To swap two scores in main, pass their addresses to the swap function. &left gets the address of left. A pointer such as a holds an address, and *a refers to the object there.

The assignment *a = *b; changes the original score. The temporary variable keeps the first score from being overwritten before the function can move it to the second position. Only dereference a pointer that points to a live object.

Exercise

What would calling swap(&left, &left) do?

Hint

Both pointers would refer to the same object.

Answer

The value of left would stay the same. Each assignment would write its original value.

Quick quiz

What does &left give to the swap function?
Show answer

The address of left. The address lets the function find and change left.

Structures and records

A point on a map has two coordinates. Use a struct to keep those coordinates together as named members. Write p.x to read the x member of the point.

A designated initializer such as .x = 2.0 names the member being initialized. For a pointer point, write point->x to reach that member through the pointer.

Exercise

Move p to the origin with one more call.

Hint

Subtract its current coordinates.

Answer

Insert translate(&p, -p.x, -p.y); before printing.

Quick quiz

How do you read the x coordinate of the structure variable p?
Show answer

p.x. The dot selects a named member of a structure.

Dynamic memory with malloc and free

When the number of elements is known only at run time, malloc can reserve an appropriately sized block. The example multiplies the element count by sizeof *values to get its size in bytes. For counts supplied by the user, check the count and guard the multiplication against overflow.

Check malloc for a null result before using the allocation. Initialize the elements before reading them. Call free once when you finish and stop using the pointer afterward.

Exercise

What should you check before allocating count elements if count comes from input?

Hint

Think about empty input and the largest value a size_t can hold.

Answer

If the program needs at least one element, require count > 0. Reject count > SIZE_MAX / sizeof *values before multiplying. Include <stdint.h> for SIZE_MAX.

Quick quiz

What should you check immediately after calling malloc?
Show answer

Whether its result is null. A null result means the storage was not allocated.

Compiler diagnostics and debugging

Compiler warnings can point to suspicious code. Start with the first diagnostic and check the line it names. Test the program with a small input whose answer you can verify yourself.

The assertion in this example records an assumption about the sum after the loop. With assertions enabled, the program stops if the assumption is false. For invalid user input, use a normal error-handling branch.

Exercise

Change i <= 4 to i < 4. Predict the resulting sum and what happens to the assertion.

Hint

Write down the sequence of counter values.

Answer

The loop sums 1, 2 and 3, yielding 6. With assertions enabled, the program stops at the failed check.

Quick quiz

What does the example use assert(sum == 10) to check?
Show answer

Whether the final sum is 10. With assertions enabled, the check fails if the sum is any value other than 10.
